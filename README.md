# Мультитул

Android-додаток, який завантажує APK з Dropbox і одразу відкриває вікно встановлення.

Зараз у списку:
- **Awax** 1.0.100
- **ESET**
- **Zillya! Антивірус** 3.8.1

Є кнопка «Завантажити все»: файли качаються паралельно, а встановлення відкриваються по черзі.

## Як отримати .apk

### Варіант 1. Android Studio (найпростіше на Mac)
1. Встанови Android Studio: https://developer.android.com/studio
2. File → Open → обери папку `multitool`.
3. Дочекайся, поки Gradle все завантажить (перший раз це кілька хвилин).
4. Build → Build App Bundle(s) / APK(s) → **Build APK(s)**.
5. Готовий файл буде тут: `app/build/outputs/apk/debug/app-debug.apk`.

Або підключи телефон кабелем (з увімкненою «Налагодженням по USB») і натисни зелену кнопку ▶ Run.

### Варіант 2. GitHub (без встановлення нічого)
1. Створи новий репозиторій на github.com і завантаж туди вміст папки `multitool`.
   Файл `github-build.yml` поклади в репозиторії за шляхом `.github/workflows/build.yml`
   (на сайті GitHub: Add file → Create new file, у назві напиши `.github/workflows/build.yml`
   і встав вміст).
2. Відкрий вкладку **Actions**: збірка запуститься сама.
3. Через ~3 хвилини внизу сторінки збірки з'явиться **multitool-apk**: це zip із готовим .apk.

## Як встановити на телефон
1. Скинь .apk на телефон (Telegram, Google Диск, кабель).
2. Відкрий його й дозволь встановлення з цього джерела.
3. Запусти «Мультитул» і натискай «Завантажити».

## Як змінити список додатків
Відкрий `app/src/main/java/ua/multitool/app/MainActivity.java` і знайди масив `APPS` на початку файлу.
Кожен рядок: назва, опис, ім'я файлу, посилання.

Посилання на файл у Dropbox: біля файлу «Копировать ссылку», а в кінці заміни `dl=0` на `dl=1`.

## Важливо
- Додаток працює тільки на Android. На iPhone встановлювати .apk неможливо.
- Якщо власник Dropbox-папки видалить або перейменує файли, посилання перестануть працювати.
- Переконайся, що маєш право поширювати ці APK (зокрема ліцензію на ESET).
